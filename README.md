# もふもふスノーボード

ぬいぐるみのクマが雪山を滑りおりる、スワイプ操作のスノーボードゲームです。
ブラウザだけで動きます（インストール・ビルド・外部ライブラリなし）。

## 遊ぶ

ローカルの HTTP サーバーで開きます（`file://` でも動きますが、
オフライン対応とホーム画面への追加には HTTP が必要です）。

```bash
python3 -m http.server 8000
# → http://localhost:8000/ をスマホ／PCのブラウザで開く
```

スマホのホーム画面に追加すると、アドレスバーのない全画面のアプリとして起動します
（PWA。一度読み込めばオフラインでも遊べます）。

## 操作

横向きの画面を推奨。左下が舵、右下がアクションです。

| 操作板 | スワイプ操作 | PC | 動作 |
| --- | --- | --- | --- |
| 左下（左半分／右半分） | 左右にドラッグ | ← → / A D | カービングして曲がる |
| 右下・上半分 | 上にスワイプ | Space / ↑ | ジャンプ |
| 空中で左下 | 空中で左右 | ← → | 回転トリック（270°ごとに加点） |
| 右下・下半分 | 下に引いたまま | ↓ / S | しゃがんで加速（空中ではグラブ） |
| ⚡ | ダブルタップ | Shift | ブースト（ゲージ50%以上で発動） |
| ⏸ | － | Esc / P | ポーズ |

### 操作板を「シーソー」にしている理由

小さな丸ボタンを2つ並べると、指がどちらの上にあるかを当てる操作になり、
押し間違えます。しかも押したまま隣へ滑らせても切り替わらないため、
間違えたら一度離してやり直すことになります。

そこで左右（および上下）をひとつづきの板にして、**触れた位置**で向きを
決めています。境界をまたいで指を滑らせればその場で切り替わるので、
押し間違えても指を動かすだけで直せます。

横方向はさらに、中心からの深さで曲がり具合が変わります（中央寄りで
0.55、端で 1.0）。ボタンの手軽さのまま、細かい舵取りもできます。

ボタンとスワイプは併用できます。横ドラッグは「支点が指についてくる」方式
なので、画面の端まで切ってからでもそのまま切り返せます。

## ルール

- 金の鈴を拾うとコンボ倍率が上がります（一定時間拾わないと途切れます）
- 鈴は近づくと吸い寄せられます。5コンボごとに音と演出が大きくなります
- 障害物（木・岩・雪だるま）に当たるとハートが1つ減り、3つ失うと終了
- **ブースト中は無敵**で、障害物を突き破って加点します
- アイスバーンに乗るとグリップが落ちて滑ります
- 進むほど速度と障害物の密度が上がります
- スコアとベスト距離は端末内（localStorage）に保存されます

## そうび

拾った鈴は走り終わりに貯金へ加算され、タイトルの「そうび」で装備を買えます。
途中でやめた場合も、そこまでに拾った鈴は持ち帰れます。

| 装備 | 効果 | 段階 |
| --- | --- | --- |
| ホットワックス | 最高速 +1.6 m/s ずつ | 4 |
| バネ入りブーツ | ジャンプ力 +11% ずつ | 4 |
| ふしぎな鈴 | 鈴の引き寄せ範囲 +35% ずつ | 3 |
| ロケットマフラー | ブーストの溜まり +30% / 持続 +0.45秒 ずつ | 3 |
| もこもこパッド | ライフ +1 ずつ（最大5） | 2 |

値段と効果量は `src/shop.js` の `DEFS` にまとめてあります。値段は
`base × 1.8^レベル`（5刻みに丸め）です。稼ぎが渋い／緩いと感じたら
`base` を上下させてください。

## つくり

画像・音声ファイルを一切持たず、風景もキャラクターも効果音もコードで生成しています。

```
index.html        画面の骨組みと HUD
styles.css        UI（タイトル・ポーズ・リザルト）
src/util.js       数値と色のユーティリティ
src/shop.js       装備の定義・コインの保存
src/audio.js      WebAudio による効果音の合成（滑走音＋SE）
src/input.js      スワイプ／キーボードの解釈
src/world.js      地形・コース・障害物の生成
src/render.js     擬似3Dの描画（空・山・雪面・オブジェクト）
src/plushie.js    ぬいぐるみライダーの描画
src/game.js       物理・当たり判定・スコア
src/main.js       起動、画面遷移、メインループ
sw.js             オフライン用キャッシュ
```

### 描画のしくみ

地面は**セグメント方式の擬似3D**です。進行方向 `z` を 2m ごとに区切り、
遠い区画から順に台形を敷き詰めます。地形の起伏は正弦波の合成
（`terrainY`）、コースの蛇行も同じく正弦波（`centerX`）で表現していて、
どちらも「その場で計算できる」ためコースデータを持ちません。

奥行き感は次の3つでつくっています。

- **大気遠近**: 遠い区画ほど色を霞の色に混ぜる（`fog()`）
- **圧雪の横縞**: 手前ほど縞のコントラストを落とす。近くで縞が巨大になると
  シマウマ模様に見えてしまうため
- **視差**: 遠景の山脈・雲をカメラの横移動に対してゆっくり動かす

山脈は「独立した峰の集まり」として持ち、峰ごとに陽の面と影の面を塗り分けて
います（日射しは右上から)。形が変わらないので一度だけオフスクリーンに描き、
毎フレームは貼るだけ。そのぶん岩の筋や雪線のギザギザまで描き込んでいます。
ゲレンデには圧雪車の溝をフォールラインに沿って引き、斜面の奥には赤い屋根の
山小屋を点在させています。

遠方の区画は画面上で1px以下に潰れるので、距離に応じて2〜4区画をまとめて
描いています。またゲレンデの塗りが画面全体を覆う手前の区画では、その下に
なる雪原の塗りを省いています（描画負荷の大半が塗り面積のため）。

### キャラクター

`plushie.js` はメートル単位で組み立て、描画時に「1mあたりのピクセル数」を
掛けています。向きは `cos(角度)` で横幅を潰し、符号が負になったら背面
（縫い目とぬいぐるみのタグ）を描くことで、板を含めた1枚絵のまま回して
見せています。

既定は進行方向を向いた**背中**で、ジャンプ中と転倒中だけ `look` が 1 に
近づきます。胴と頭で角度を別々に持たせているので、体は前を向いたまま
頭だけがこちらを向く「肩越しの振り返り」になります。

## 調整したいとき

| 項目 | 場所 |
| --- | --- |
| コース幅・描画距離 | `src/world.js` の `C` |
| 地形のうねり・蛇行 | `src/world.js` の `terrainY` / `centerX` |
| 障害物の種類と出現比率 | `src/world.js` の `spawnPattern` |
| 速度・ジャンプ・回転 | `src/game.js` の `update` / `jump` |
| カメラ位置・画角 | `src/game.js` の `CAM_BACK` / `CAM_HEIGHT`、`render.js` の `setCamera` |
| 配色 | `src/render.js` の `PAL`、`src/plushie.js` の先頭 |
